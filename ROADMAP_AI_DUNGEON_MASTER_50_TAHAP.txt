================================================================================
  ROADMAP PROJEK AMBISIUS: AI DUNGEON MASTER & VIRTUAL TABLETOP RPG (D&D ENGINE)
  Tech Stack: React + Vite, Node.js + Express, MySQL (Sequelize ORM), JWT Auth,
              Socket.IO, Web Audio/Speech API, 3D Dice Engine, Free LLM (Gemini/Groq/Ollama)
  Database Name: ai_dungeon_vtt
================================================================================

================================================================================
FASE 1: CORE RPG FOUNDATION & CHARACTER STUDIO
[TARGET MVP 1]: Aplikasi web yang bisa Register/Login (JWT), membuat karakter D&D 5E lengkap (Stat, Class, Race, Spells, Inventory) yang tersimpan di MySQL via Sequelize, serta interaktif melempar dadu 3D di layar secara visual.
--------------------------------------------------------------------------------
01. Modular Architecture Setup (Strict Backend & Frontend Separation):
    Pemisahan direktori dan environment kerja secara mandiri (Frontend: React + Vite di folder `client/`, Backend: Node.js + Express di folder `server/`), konfigurasi database `ai_dungeon_vtt` dengan Sequelize ORM, dan standalone launch scripts.
02. Open-Access Character & Session Manager (Auth Postponed):
    Sistem manajemen petualang langsung tanpa login/registrasi (langsung masuk ke studio karakter & permainan), sementara sistem JWT Auth, User Security Hardening, dan Proteksi Akun dialihkan ke Fase 10 (Production Polish).
03. MySQL & Sequelize Schema Foundation:
    Konfigurasi koneksi MySQL dengan Sequelize ORM, mendesain model dasar (User, Character, CharacterStats, InventoryItem, Spell) beserta migrasi dan sinkronisasi tabel otomatis.
04. Dark Fantasy RPG Design System & Theme Engine:
    Membangun fondasi UI kustom bernuansa tabletop RPG premium (HSL token colors, dark mode, glassmorphic panels, medieval/fantasy fonts, button click feedback, dan modal manager).
05. Dynamic Character Creation Studio & D&D 5E Stat Engine:
    Formulir pembuatan karakter interaktif (pemilihan Race, Class, Background) dengan kalkulator otomatis D&D 5E (STR, DEX, CON, INT, WIS, CHA, Armor Class, Hit Points, Proficiency Modifier).
06. Interactive 3D Physics Dice Box Engine:
    Mengintegrasikan engine dadu 3D berbasis WebGL (Three.js/Dice-Box) di browser untuk melempar D4, D6, D8, D10, D12, D20, dan D100 dengan animasi fisik realistis dan deteksi hasil otomatis.
07. Character Sheet Dashboard & Stat Modification:
    Halaman ringkasan karakter hidup (live sheet) untuk melihat status, menambah/mengurangi HP secara real-time, menaikkan level (Level-Up), dan melihat kalkulasi ability checks.
================================================================================

================================================================================
FASE 2: INVENTORY, EQUIPMENT & SPELLBOOK SYSTEM
[TARGET MVP 2]: Sistem inventaris visual grid drag-and-drop, perlengkapan senjata/armor yang memengaruhi stat karakter secara real-time, katalog spellbook aktif, serta REST API CRUD Sequelize untuk item & spells.
--------------------------------------------------------------------------------
08. Sequelize Relational Models for Itemization & Spells:
    Membuat model relasi Sequelize untuk Item catalog, CharacterInventory, EquipmentSlots, Spells, dan SpellSlots dengan auto-seeder ratusan item/spell dasar D&D 5E.
09. Drag-and-Drop Grid Inventory System:
    Membangun antarmuka tas inventaris interaktif drag-and-drop di React (grid-based bag) dengan filter kategori (Weapons, Armor, Potions, Quest Items) dan indikator kapasitas beban (Weight/Encumbrance).
10. Equipment Slot & Dynamic Stat Sync:
    Sistem slot perlengkapan karakter (Head, Armor, Main Hand, Off Hand, Rings, Boots) di mana memakai item (misal: Shield / Plate Armor) otomatis mengupdate Armor Class (AC) dan status serangan di Character Sheet.
11. Spellbook Manager & Spell Slot Tracker:
    Katalog mantra sihir (Cantrips hingga Level 9) dengan filter class/school of magic, deskripsi efek, jangkauan (range), serta pengurang spell-slot interaktif saat mantra digunakan.
12. Status Condition & Buff/Debuff System:
    Sistem penanda kondisi karakter (Poisoned, Stunned, Charmed, Blinded, Blessed) dengan visual badge dan otomatisasi kalkulasi penalti/bonus pada lemparan dadu.
================================================================================

================================================================================
FASE 3: SINGLE-PLAYER AI DUNGEON MASTER (THE CORE NARRATOR)
[TARGET MVP 3]: Petualangan RPG single-player yang sepenuhnya hidup! Pemain berinteraksi bebas lewat chat/voice dengan AI DM (Gemini/Groq gratis), AI merespon dengan narasi streaming, meminta lemparan dadu DC, dan otomatis memanipulasi HP/inventory pemain melalui Function Calling.
--------------------------------------------------------------------------------
13. Free LLM Provider Gateway (Gemini & Groq Adapter):
    Backend service untuk menghubungkan Express ke API gratis Google Gemini 1.5 Flash dan Groq (Llama 3) dengan streaming text response dan token management.
14. AI Dungeon Master Prompting & Rule Arbiter:
    Arsitektur system prompt untuk AI Dungeon Master yang memiliki kepribadian narator epik, memahami aturan D&D 5E, memandu narasi, dan menyajikan situasi yang menantang.
15. Function Calling Engine for Live State Mutation:
    Mengintegrasikan structured function calling pada LLM agar AI bisa mengeksekusi aksi database langsung (misal: memanggil `takeDamage(5)`, `giveItem('Kunci Besi')`, `awardGold(20)`).
16. Dynamic Skill Check & D20 Resolution Loop:
    Mekanisme di mana AI mendeteksi aksi berisiko dari pemain -> menentukan target Difficulty Class (DC) -> memunculkan pop-up dadu 3D di layar -> memproses hasil roll (Critical Success / Failure) ke narasi kelanjutan.
17. Long-Term Story Memory & Session Journaling (Sequelize):
    Mekanisme penyimpanan riwayat petualangan (GameSessions, StoryLogs) ke MySQL dengan teknik context summarization agar AI tetap mengingat kejadian awal petualangan tanpa overload token.
18. Cinematic Typewriter & Web Speech TTS / STT:
    Efek teks narasi mengalir (*typewriter effect*), integrasi Web Speech API untuk membacakan narasi AI dengan suara (TTS), dan input aksi menggunakan suara pemain lewat mikrofon (Speech-to-Text).
================================================================================

FASE 4: VISUAL NOVEL SCENERY & ADAPTIVE AUDIO ENGINE
[TARGET MVP 4]: Pengalaman bermain berubah dari sekadar teks menjadi visual novel interaktif: background lokasi dinamis berganti otomatis sesuai alur cerita AI, efek cuaca visual canvas, sound effect (SFX), dan musik atmosferik yang berganti otomatis saat situasi berubah.
--------------------------------------------------------------------------------
19. Dynamic Background Scenery & Scene Director:
    Sistem rendering panggung visual novel yang merespons kata kunci / tag dari AI DM untuk berganti latar tempat (Tavern, Dungeon, Hutan Gelap, Istana Raja) secara transisi mulus.
20. Canvas Particle Weather & Atmospheric VFX:
    Engine overlay visual di React Canvas untuk menciptakan efek lingkungan dinamis (hujan badai, salju turun, kobaran api/bara, kabut misterius, efek gempa layar/screen shake).
21. Adaptive Ambient Soundtrack Studio (Web Audio API):
    Sound manager yang memutar musik latar atmosferik secara seamless, dengan transisi crossfade otomatis saat intensitas cerita berubah (Peaceful Exploration -> Suspense/Tension -> Boss Battle).
22. Contextual Sound Effects (SFX) Trigger Engine:
    Soundboard audio interaktif yang otomatis membunyikan efek suara (dentang pedang, mantra sihir, langkah kaki, pintu berderit, koin bergemerincing) berdasarkan event cerita yang dipicu oleh AI.
23. Interactive World Map Explorer & Fog of War:
    Peta wilayah interaktif (Canvas/SVG) di mana pemain dapat mengeklik node lokasi untuk berpindah tempat, membuka area berkabut (Fog of War), dan memicu narasi perjalanan dari AI DM.

FASE 5: TACTICAL 2D GRID COMBAT & MONSTER BESTIARY
[TARGET MVP 5]: Mode pertarungan taktis (Battle Mode) berbasis petak grid 2D di browser. Pemain dan monster bergantian giliran (Turn-Based), menggerakkan token di atas peta tempur, melancarkan serangan/sihir dengan animasi VFX, dan menerima loot/EXP otomatis.
--------------------------------------------------------------------------------
24. Sequelize Bestiary & Monster Database:
    Model dan data katalog monster D&D 5E lengkap di MySQL (Goblin, Orc, Skeleton, Dragon) beserta status HP, Armor Class, Action serangan, spell, dan Challenge Rating (CR).
25. 2D Interactive Battle Grid Map:
    Papan catur pertempuran (Grid Map) berbasis Canvas/SVG dengan sistem koordinat petak, penempatan bidak token (pemain & musuh), serta visualisasi jarak langkah (Movement Range).
26. Turn-Based Initiative & Action Economy Engine:
    Sistem urutan giliran otomatis (Initiative Roll), manajemen kuota giliran (Action, Bonus Action, Reaction, Movement), dan status Death Saving Throws jika HP mencapai 0.
27. Monster AI Behavior Engine:
    Logika kecerdasan buatan musuh (Aggressive Melee, Cunning Ranged, Spellcaster) yang otomatis memilih target terdekat, bergerak mendekat, dan melancarkan serangan ke pemain saat giliran monster.
28. Spell VFX, Attack Animations & Floating Damage Numbers:
    Visual animasi efek pertempuran (proyektil sihir, tebasan pedang, lingkaran ledakan AoE) dan angka damage/heal melayang (floating popups) di atas bidak token.
29. Battle Reward & Loot Distribution Engine:
    Layar kemenangan pertarungan yang menghitung perolehan EXP, kenaikan level, pembagian koin emas, dan generator drop item acak ke dalam inventaris pemain.

FASE 6: NO-CODE CAMPAIGN & WORLD BUILDER STUDIO
[TARGET MVP 6]: Creator Studio lengkap di mana pengguna bisa membuat modul petualangan (Campaign) sendiri tanpa koding: mendesain alur quest visual (Node Graph React Flow), menulis Lorebook dunia, membuat custom monster, dan membagikan campaign ke pemain lain.
--------------------------------------------------------------------------------
30. Sequelize Campaign & Quest Graph Schema:
    Perancangan tabel relasi Sequelize untuk Campaigns, Quests, StoryNodes, CustomMonsters, LoreCodex, dan WorldSettings.
31. Visual Node-Graph Quest Flow Builder (React Flow):
    Editor visual drag-and-drop di frontend untuk merangkai bagan pohon cerita: menentukan node quest, kondisi trigger pilihan, jebakan tersembunyi, dan cabang percabangan alur petualangan.
32. World Codex & Lorebook Creator:
    Antarmuka pembuatan dokumen ensiklopedia dunia (sejarah kerajaan, faksi, pantangan sihir, profil karakter kunci) yang otomatis disuntikkan menjadi memori referensi AI DM saat campaign dimainkan.
33. Custom Monster & NPC Creator Studio:
    Formulir pembuatan monster dan NPC kustom dengan ability khusus, serangan unik, deskripsi perilaku, dan potret avatar kustom.
34. Dungeon Map Tile Painter Tool:
    Aplikasi web sederhana untuk menggambar tata letak ruangan dungeon (meletakkan dinding, lantai batu, pintu terkunci, peti harta karun) yang langsung bisa dimuat ke mode battle grid.
35. Campaign Exporter, Importer & Public Showcase:
    Sistem publikasi campaign, export data campaign ke file JSON, import modul pemain lain, dan halaman galeri komunitas untuk memainkan petualangan karya kreator lain.

FASE 7: REALTIME MULTIPLAYER CO-OP PARTY (VTT)
[TARGET MVP 7]: Mode bermain bersama (Multiplayer Virtual Tabletop) via Socket.IO. Pemain bisa membuat Room Party, mengundang 2–4 teman, melempar dadu 3D di layar bersama secara realtime, berbagi chat log pertempuran, dan bermain bersama AI DM secara serentak.
--------------------------------------------------------------------------------
36. Socket.IO Realtime Room & Lobby Engine:
    Arsitektur backend Socket.IO di Express untuk membuat Room Game via Kode PIN unik, sinkronisasi kehadiran pemain (Player Join/Leave), dan pemilihan karakter party.
37. Synchronized Multiplayer 3D Dice Tray:
    Sistem melempar dadu bersama di mana saat salah satu pemain melempar dadu di komputernya, seluruh anggota party di room melihat animasi lemparan dadu 3D tersebut berputar secara real-time.
38. Shared Narrative Log & Party Action Feed:
    Stream riwayat percakapan dan narasi AI DM yang sinkron antar semua pemain, dilengkapi penanda siapa pemain yang sedang mengambil giliran aksi (*turn indicator*).
39. Multiplayer Grid Battle Synchronizer:
    Sinkronisasi pergerakan token bidak pemain dan monster di grid battle map 2D secara real-time antar semua anggota party.
40. Tactical Ping & Live Whiteboard Drawing:
    Fitur bagi pemain dan DM untuk menandai target di peta (*tactical ping*) dan menggambar coretan strategi garis/panah di atas peta pertempuran secara bersamaan.

FASE 8: RPG ECONOMY, CRAFTING & PROCEDURAL ROGUELIKE
[TARGET MVP 8]: Fitur dunia yang kaya: Pasar toko/vendor dengan sistem tawar-menawar (Barter), sistem crafting ramuan/senjata dari bahan loot, sistem perkemahan malam hari (Resting), dan dungeon tak terbatas yang dihasilkan secara acak (Procedural Roguelike).
--------------------------------------------------------------------------------
41. Dynamic Shopkeeper, Merchant & Barter System:
    Sistem toko pedagang di dalam game: beli/jual item dengan harga dinamis, serta opsi bernegosiasi/intimidasi ke pedagang via lemparan dadu Charisma ke AI DM.
42. Alchemy, Blacksmithing & Recipe Crafting:
    Sistem crafting di mana pemain dapat mengombinasikan bahan mentah (monster parts, herbs, ore) untuk meracik ramuan kesehatan, racun, senjata tajam, dan armor sihir.
43. Campfire & Resting Mechanics (Short & Long Rest):
    Sistem mendirikan perkemahan malam untuk memulihkan HP, memulihkan Spell Slots, dengan event acak malam hari (diserang monster malam, cerita antar karakter).
44. Procedural Random Dungeon Generator (BSP Algorithm):
    Generator ruangan dungeon labirin acak menggunakan algoritma Binary Space Partitioning (BSP) yang menghasilkan tata letak kamar, koridor, pintu, dan peti harta karun baru secara otomatis di setiap permainan.

FASE 9: CHRONICLE NOVELIZER, AUDIO-COMM & TWEAKS
[TARGET MVP 9]: AI Story Novelizer yang otomatis merangkum sesi main menjadi bab novel epik yang bisa didownload PDF, in-game voice chat P2P antar party (WebRTC), dan konsol command `/roll` untuk power user.
--------------------------------------------------------------------------------
45. Automated Story Chronicle & PDF Novel Exporter:
    Modul AI yang menganalisis seluruh log sesi permainan dan merangkumnya menjadi cerita novel bergaya sastra fantasi lengkap dengan judul bab dan export ke format PDF / Text.
46. In-Game WebRTC P2P Voice Chat Mesh:
    Integrasi komunikasi suara (Voice Chat) langsung antar anggota party di browser menggunakan WebRTC tanpa aplikasi luar seperti Discord.
47. In-Game Developer / DM Cheat Console & Macro Engine:
    Terminal konsol di dalam game untuk mengeksekusi rumus dadu cepat (misal: `/roll 4d6kh3 + 2`), spawn item instan, atau inject narasi khusus.
48. Character Legacy & Hall of Fame:
    Sistem memorial bagi karakter yang gugur (Graveyard) dan piala penghargaan (Hall of Fame) yang mewariskan item pusaka ke karakter baru yang dibuat berikutnya.
