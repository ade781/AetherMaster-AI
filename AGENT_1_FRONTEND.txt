2. DETAIL TUGAS & INSTRUKSI TEKNIS
--------------------------------------------------------------------------------

### TUGAS 1.1: Pembersihan Dependency Frontend (Three.js & Canvas Confetti)
- Di `frontend/package.json`:
  * HAPUS dependency:
    - "three"
    - "@types/three"
    - "canvas-confetti"
  * PERTAHANKAN:
    - react, react-dom, @vitejs/plugin-react, vite, tailwindcss, postcss, autoprefixer, lucide-react, framer-motion.
- HAPUS folder `frontend/public/assets/3d/`.
- Jalankan `npm install` di dalam direktori `frontend/` untuk menyinkronkan `package-lock.json`.

### TUGAS 1.2: Penghapusan JournalModal & QuestModal
- HAPUS file:
  * `frontend/src/components/JournalModal.jsx`
  * `frontend/src/components/QuestModal.jsx`
- Di `frontend/src/App.jsx`:
  * Hapus import `JournalModal` dan `QuestModal`.
  * Hapus state `isJournalOpen` dan `isQuestOpen` (atau sejenisnya).
  * Hapus rendering `<JournalModal ... />` dan `<QuestModal ... />`.
- Di `frontend/src/components/VisualNovelStage.jsx`:
  * Hapus tombol Journal (`topbar-btn-journal`, `journal-card-btn-journal`) dan Quest (`journal-card-btn-quest`).
  * Hapus shortcut keyboard listener untuk 'J' dan 'Q'.
  * Bersihkan props/handler yang sebelumnya meneruskan aksi buka Journal / Quest.
- Di `frontend/src/components/CharacterHUD.jsx`:
  * Hapus tombol atau ikon trigger Journal / Quest jika ada.
  * Tampilkan hanya informasi esensial karakter: Potret/Nama, HP/Mana/Gold, Active Objective singkat (jika ada di session/questState), dan tombol esensial (Inventory, Story Tree, Menu/Save).

### TUGAS 1.3: Sederhanakan Character Creation
- Di `frontend/src/components/CharacterCreationModal.jsx`:
  * Pangkas daftar class dari 9 pilihan menjadi 4 class klasik:
    1. Warrior (Fokus: HP tinggi, Strength, pertarungan fisik)
    2. Rogue (Fokus: Agility, stealth, critical, kelincahan)
    3. Mage (Fokus: Intelligence, Mana besar, spellcasting)
    4. Paladin (Fokus: Hybrid tank & holy support)
  * Hapus class berlebih seperti bard, warlock, wizard, cleric, ranger jika hanya menghasilkan variasi stat minor.
  * Pastikan UI pilihan class responsif, rapi, dan langsung menampilkan base stat & deskripsi class secara elegan.

### TUGAS 1.4: Sederhanakan Save / Load Modal
- Di `frontend/src/components/SaveLoadModal.jsx`:
  * Ubah tampilan slot save menjadi:
    - Slot 0: Auto Save (Hanya bisa dimuat / Load)
    - Slot 1: Manual Save 1
    - Slot 2: Manual Save 2
    - Slot 3: Manual Save 3
  * Hapus slot manual ke-4 dan ke-5 (tidak perlu 6 slot).
  * Pastikan fungsi Save ke Slot (1-3) dan Load dari Slot (0-3) tetap berfungsi normal via API `/api/story/saves`.

### TUGAS 1.5: Sederhanakan Landing Page
- HAPUS file `frontend/src/components/landing/FeaturesShowcase.jsx`.
- Di `frontend/src/components/LandingPage.jsx`:
  * Hapus import dan komponen `FeaturesShowcase`.
  * Fokuskan landing page menjadi visual dan to-the-point:
    - Judul & Logo: AETHERMASTER AI
    - Tagline visual novel RPG dengan AI Dungeon Master
    - Banner / Ilustrasi suasana cerita
    - Tombol utama: "Mulai Petualangan" / "Lanjutkan"
    - Tidak perlu menampilkan 12 kartu fitur teknis yang membingungkan calon pemain.

### TUGAS 1.6: Sederhanakan Audio Service
- Di `frontend/src/services/audioService.js`:
  * Hapus sistem pemutaran MP3 BGM yang berat (`bgm_boss.mp3`, `bgm_combat.mp3`, dll) dan BGM playlist manager yang menimbulkan autoplay blocker.
  * PERTAHANKAN:
    - Web Audio procedural SFX (click, select, sword clash, heal, magic, heartbeat).
    - Procedural ambient sound generator (drone/synth ambient via Web Audio oscillator).
    - Narration TTS (Edge TTS via backend, dengan fallback SpeechSynthesis bawaan browser).
  * Bersihkan fungsi mati seperti `playDiceRoll()` dan konfigurasi audio slider berlebih jika UI tidak memakainya.

3. KONTRAK ANTAR-AGEN (AGREEMENT)
--------------------------------------------------------------------------------
- Base URL API tetap: `/api/story` (contoh: `http://localhost:5000/api/story`).
- Endpoint yang tetap dipanggil oleh Frontend:
  * GET  `/api/story/campaigns`
  * POST `/api/story/start`
  * POST `/api/story/action`
  * POST `/api/story/combat/action`
  * POST `/api/story/use-item`
  * GET  `/api/story/tree/:sessionId`
  * POST `/api/story/rewind`
  * GET  `/api/story/backlog/:sessionId`
  * GET  `/api/story/session/:sessionId`
  * GET  `/api/story/saves`
  * POST `/api/story/saves/save`
  * GET  `/api/story/saves/load/:slotNumber`
  * POST `/api/story/tts`
- Frontend TIDAK LAGI memanggil `/journal` atau `/quests` (karena Agent 2 akan menghapus endpoint tersebut).
