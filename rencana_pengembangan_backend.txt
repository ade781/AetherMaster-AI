2. FASE 1: PEROMBAKAN TOTAL DATABASE (MODELS, MIGRATION & SEEDER 20 CERITA)
--------------------------------------------------------------------------------
[ ] 1.1. Perombakan Model `Campaign.js` (`backend/src/models/Campaign.js`)
    - Perbarui definisi skema Sequelize:
      * `id`: STRING (Primary Key)
      * `title`: STRING (Judul Kampanye)
      * `premise`: TEXT (Latar Belakang / Premis Narasi)
      * `introDialogue`: TEXT (Dialog Pengantar Pembuka Cerita)
      * `genre`: STRING (dark_fantasy, gothic_horror, eldritch, dll)
      * `threatLevel`: STRING (Tier 1 s.d Tier 4)
      * `recommendedClasses`: JSON (Array string nama-nama kelas ideal)
      * `primarySkill`: STRING (Atribut/Skill utama yang diuji)

      * `defaultNpcId`: STRING (Aset NPC pembicara awal)
      * `icon`: STRING (Emoji / symbol icon)
      * `coverImage`: STRING (Path banner visual kampanye)
      * `factions`: JSON (Array faksi yang berkuasa di wilayah kampanye)

[ ] 1.2. Perombakan Model `GameSession.js` (`backend/src/models/GameSession.js`)
    - Tambahkan kolom baru untuk mendukung pertempuran taktis:
      * `combatState`: JSON (Menyimpan status musuh aktif, turn round, dan combat log)
      * `worldLedger`: JSON (Diperluas dengan sub-objek `questFlags` dan `reputation`)

[ ] 1.3. Perombakan Model `Character.js` (`backend/src/models/Character.js`)
    - Tambahkan kolom pendukung sistem perlengkapan D&D 5E:
      * `armorClass`: INTEGER (Default 10 + dexModifier, terpengaruh zirah/perisai)
      * `equippedItems`: JSON (Array item yang sedang aktif dipakai di tubuh)

[ ] 1.4. Pembuatan Skrip Seeder Terpusat `backend/src/models/seeders/campaignSeeder.js`
    - Memasukkan seluruh 20 Master Kampanye dari Bagian 8 dokumen ini secara presisi.

[ ] 1.5. Pembuatan Skrip Eksekusi Perombakan: `backend/src/scripts/reset_and_seed_db.js`
    - Menghapus database ganda `backend/database.sqlite`.
    - Melakukan `sequelize.sync({ force: true })` untuk me-reset tabel dengan skema baru.
    - Menjalankan `campaignSeeder.js` untuk menyuntikkan 20 kampanye lengkap.
    - Cetak log konfirmasi: "Database successfully overhauled with 20 campaigns seeded".

[ ] 1.6. Pembaruan Endpoint `GET /api/story/campaigns`
    - Memastikan endpoint mengembalikan seluruh kolom baru dari database untuk dikonsumsi frontend.
