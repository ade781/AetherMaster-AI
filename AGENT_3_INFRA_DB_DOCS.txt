2. DETAIL TUGAS & INSTRUKSI TEKNIS
--------------------------------------------------------------------------------

### TUGAS 3.1: Penghapusan QuestObjective & Simplifikasi Model
- HAPUS file:
  * `backend/src/models/QuestObjective.js`
- Di `backend/src/models/index.js`:
  * Hapus `const QuestObjective = require('./QuestObjective');`
  * Hapus relasi:
    - `Quest.hasMany(QuestObjective, ...)`
    - `QuestObjective.belongsTo(Quest, ...)`
  * Hapus `QuestObjective` dari export `module.exports = { ... }`.
- Di `backend/src/models/seeders/worldDataSeeder.js`:
  * Hapus import dan eksekusi seeder untuk `QuestObjective`.
  * Catatan: State quest dalam gameplay interactive visual novel kini cukup ditangani secara dinamis melalui `GameSession.questState` / `currentObjective` tanpa overhead tabel relasional terpisah.

### TUGAS 3.2: Penghapusan QuestRepository
- HAPUS file:
  * `backend/src/repositories/QuestRepository.js`
- Di `backend/src/repositories/index.js`:
  * Hapus import dan export `QuestRepository`.
  * Pertahankan repository yang benar-benar aktif: CampaignRepository, CharacterRepository (jika ada), StoryNodeRepository, StoryChoiceRepository, SnapshotRepository, WorldFactRepository, ItemRepository.

### TUGAS 3.3: Konsolidasi Konfigurasi Database (database.js)
- Di `backend/src/config/database.js`:
  * Rapikan konfigurasi koneksi Sequelize.
  * Hapus logika "database buffet" yang redundan. Tetapkan konfigurasi yang jelas:
    - Jika `DATABASE_URL` tersedia -> Gunakan PostgreSQL (untuk cloud deployment seperti Supabase / Neon / Render).
    - Jika di lokal tanpa DATABASE_URL -> Default ke MySQL atau PostgreSQL (sesuai environment .env).
  * Pastikan logging dan pool connection terkonfigurasi efisien dan tidak ada memory leak.

### TUGAS 3.4: Penghapusan Automasi World Architect & Pembersihan Root package.json
- HAPUS file:
  * `.github/workflows/world_architect.yml`
  * `scripts/run_antigravity_agent.js`
- Di `package.json` (Root):
  * Hapus script yang memanggil automasi tersebut pada baris 13-18:
    - "world:generate"
    - "world:30m"
    - "world:log"
    - "agent:cloud"
    - "agent:30m"
    - "agent:log"
  * Bersihkan dependensi root yang tidak diperlukan jika ada (misal `bcryptjs`, `jsonwebtoken` jika terpasang ganda di root).

### TUGAS 3.5: Buat Dokumentasi Arsitektur Baru (docs/ARCHITECTURE.md)
- Buat file `docs/ARCHITECTURE.md` yang ringkas, modern, dan padat (maksimal 150-250 baris), mencakup:
  1. System Architecture Diagram (Core AI Visual Novel RPG flow).
  2. Runtime Flow (Player Action -> Intent Resolver -> Context Builder -> Gemini / Fallback -> Game State Engine -> Branching StoryNode Graph).
  3. Database Schema Ringkas (Campaign, Character, GameSession, StoryNode, StoryChoice, StorySnapshot, WorldFact, Item).
  4. Audio System (Procedural Web Audio SFX + Ambient + Neural Edge TTS fallback Web Speech API).
  5. Save / Load Protocol (Slot 0 Auto Save, Slot 1-3 Manual Save).

### TUGAS 3.6: Pembaruan README.md
- Rampingkan `README.md`:
  * Hapus semua klaim legacy:
    - Hapus klaim "3D Dice Physics / Three.js / Canvas Confetti".
    - Hapus klaim "100% Local Audio" jika sistem sekarang menggunakan arsitektur hybrid (Edge TTS + Procedural Web Audio).
    - Perbarui jumlah slot simpan menjadi 4 slot (1 auto + 3 manual).
  * Tampilkan petunjuk setup cepat yang jelas:
    - `npm run install:all`
    - Setup `.env` (GEMINI_API_KEY, DATABASE_URL)
    - `npm run dev`
  * Berikan gambaran fitur inti: AI Narrative Dungeon Master, Visual Novel Stage, Persistent World State, Branching Choices, Turn-based Encounter, Multi-slot Save.
