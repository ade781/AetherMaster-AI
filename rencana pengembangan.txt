================================================================================
1. BATASAN LINGKUNGAN PENGEMBANGAN (LOCAL-ONLY CONSTRAINTS)
================================================================================
Agar performa maksimal, data terjaga rapi, dan sistem mudah dioperasikan di laptop:
1. Local Server: Backend berjalan di `http://localhost:5000` via Node.js Express.
2. Local Client: Frontend berjalan di `http://localhost:5173` via Vite React.
3. Local Database: Single-file SQLite berlokasi di `backend/ai_dungeon_vtt.sqlite`.
   Tidak menggunakan cloud RDS / cloud Postgres / MongoDB Atlas.
4. Local Asset Storage: Seluruh aset visual (backgrounds, portraits, items, icons) 
   disimpan langsung di `frontend/public/assets/` dalam format PNG/WEBP.
5. Local Audio Synth & SFX: Menggunakan Web Audio API internal browser untuk synthesizer 
   ambient dinamis dan efek suara klik/dadu tanpa ketergantungan koneksi pihak ketiga.
6. Offline Fallback Logic: Jika API Key Gemini habis limit atau tidak ada internet, 
   engine otomatis mengalihkan alur ke *Deterministic Story Tree Fallback* sehingga 
   game tetap bisa dimainkan tanpa crash.

3. FITUR UTAMA SISTEM GAMEPLAY (THE 10 PILLARS OF AETHERMASTER)
================================================================================

3.1. D&D 5E CHARACTER BUILDER & ATTRIBUTE MATRIX
Pemain dapat meracik karakter petualang sebelum memulai kampanye:
- Pilihan Class:
  * Warrior (Fighter): Mahir senjata, bonus STR & CON, HP tertinggi.
  * Rogue: Mahir mengendap-endap, membuka kunci, bonus DEX & INT.
  * Mage (Wizard): Mahir mantra mistis, analisa sihir, bonus INT & WIS.
  * Cleric: Mahir penyembuhan, pertahanan suci, bonus WIS & STR.
- Sistem 6 Atribut D&D (Modifier = (Stat - 10) / 2):
  * STR (Kekuatan Fisik, Dobrakan, Serangan Jarak Dekat)
  * DEX (Kelincahan, Refleks, Stealth, Membuka Gembok)
  * INT (Pengetahuan Arkanum, Investigasi, Bahasa Kuno)
  * WIS (Persepsi Firasat Bahaya, Tekad Mental, Pengobatan)
  * CHA (Persuasi, Intimidasi, Negosiasi Harga)
  * CON (Daya Tahan Tubuh, Penentu Hit Points)
- Health Points (HP) & Mana/Aether Pool:
  * HP: 0 = Karakter Tewas / Death Scene.
  * Mana: Diperlukan untuk merapal mantra tingkat tinggi saat encounter.

3.2. THREE.JS 3D VIRTUAL D20 DICE ROLLER
- Saat pemain memilih opsi aksi yang memerlukan uji keahlian (contoh: `[STR DC 14]`), 
  overlay 3D muncul di tengah panggung VN.
- Model 3D Icosahedron (D20) berputar secara dinamis dengan pencahayaan specular 
  dan berhenti menampilkan angka acak yang dihitung dari backend dice engine.
- Tampilan Kalkulasi Transparan di Layar:
  `[Hasil Dadu: 12] + [STR Mod: +3] = 15 vs DC 14 -> SUKSES!`
- Nat 20: Memicu suara gemerincing emas dan semburan partikel confetti.
- Nat 1: Memicu efek layar bergetar merah (screen shake) dan suara petaka.

3.3. TURN-BASED TACTICAL COMBAT ENCOUNTER (MINI-VTT)
Ketika cerita mencapai pertempuran sengit melawan monster/bos:
- Panggung visual novel bertransisi ke mode Combat Stage.
- Musuh ditampilkan dengan Card Portrait, Armor Class (AC), dan Bar HP Merah.
- Menu Perintah Pemain:
  * [Serang / Attack]: Melempar D20 Attack Roll vs Target AC. Jika tembus, lempar Damage Roll.
  * [Mantra / Spell]: Melancarkan Fireball (Area Damage), Holy Heal (Pulihkan HP), atau Shadow Step.
  * [Item]: Memakai Potion dari kantong tas.
  * [Taktik / Flee]: Memanfaatkan lingkungan untuk menjebak musuh atau kabur.
- Combat Log interaktif mencatat setiap giliran ronde pertempuran secara runtut.

3.4. INTERACTIVE 6-SLOT GRID INVENTORY SYSTEM
- Panel tas mengambang yang dapat dibuka kapan saja melalui tombol tas atau hotkey `I`.
- Menampilkan 6 slot barang bawaan dengan ikon definisi tinggi.
- Klik item untuk membuka Modal Detail:
  * Nama Item, Kategori (Senjata, Obat, Kunci, Relik Kuno).
  * Efek Pasif / Aktif (cth: "Memulihkan 25 HP" atau "+2 Bonus WIS saat dipakai").
- Item Requirement Check: Opsi pilihan cerita tertentu hanya aktif jika tas 
  memiliki item kunci yang diminta (misal: "Buka Peti Kuno [Butuh Kunci Tengkorak]").

3.5. RELATIONAL BRANCHING STORY TREE & REWIND ENGINE
- Modal visualisasi pohon keputusan yang memetakan alur cerita secara grafis.
- Node yang sudah dilewati berwarna emas terang, node yang belum terbuka terkunci abu-abu.
- Rewind to Checkpoint: Jika pemain tewas di tengah dungeon atau salah mengambil keputusan 
  fatal, pemain bisa me-rewind kembali ke cabang sebelumnya tanpa harus mengulang 
  kampanye dari nol.

3.6. PERSISTENT WORLD LEDGER & FACTION REPUTATION
- Menyimpan fakta-fakta penting dunia secara permanen di SQLite:
  * `questFlags`: {'barkeep_saved': true, 'vampire_deal_rejected': true}
  * `reputation`: {'guild_thieves': -10, 'order_paladins': +25}
- Data Ledger ini otomatis disuntikkan ke konteks Gemini AI di setiap giliran sehingga 
  karakter NPC mengingat janji, hutang, atau perbuatan buruk pemain di babak sebelumnya.

3.7. LAYERED ATMOSPHERIC SOUNDSCAPE (WEB AUDIO SYNTH)
- Menggunakan Web Audio API lokal untuk menciptakan latar audio prosedural:
  * Suara deru angin badai musim dingin.
  * Suara gemersik hujan di atap kedai.
  * Suara degup jantung saat HP kritis (< 20%).
- SFX Sintesis: Suara lemparan dadu kayu, denting pedang beradu, bunyi koin emas, 
  dan suara langkah kaki di lantai batu.

3.8. PROFESSIONAL VISUAL NOVEL STAGE LAYOUT
- Layar panggung 16:9 yang imersif:
  * Background Full HD dengan transisi cross-fade lembut antar-lokasi.
  * Sprite Bust Karakter di kiri/kanan panggung dengan ekspresi wajah yang berubah.
  * Kotak Dialog Kayu Berukir dengan efek Typewriter teks yang dapat di-skip (klik/spasi).
  * Nameplate pembicara yang elegan lengkap dengan ikon peran (Barkeep, Boss, Arwah).

3.9. MULTI-SLOT LOCAL SAVE/LOAD & JSON DATA PORTER
- Fitur simpan permainan lokal dengan 3 Slot Manual Save + 1 Auto Save.
- Setiap save game mencatat waktu, judul bab, status karakter, dan thumbnail panggung.
- Fitur Export/Import JSON: Pemain dapat mengunduh save game ke file `.json` lokal 
  dan memuatnya kembali kapan saja.

3.10. WEB SPEECH API NARRATION (VOICE GATEWAY)
- Menggunakan sintesis suara lokal bawaan browser (SpeechSynthesis API).
- Narasi cerita dapat dibacakan secara otomatis dengan suara narator yang tenang 
  dan artikulatif dalam Bahasa Indonesia/Inggris (dapat dinyalakan/dimatikan dengan 1 klik).


================================================================================
4. DESAIN DATABASE LENGKAP (SEQUELIZE SQLITE: ai_dungeon_vtt.sqlite)
================================================================================

4.1. Tabel `Characters`:
- `id` (STRING/UUID, Primary Key)
- `name` (STRING, nama petualang)
- `race` (STRING: 'human', 'elf', 'dwarf', 'tiefling', 'dragonborn')
- `characterClass` (STRING: 'warrior', 'rogue', 'mage', 'cleric')
- `level` (INTEGER, default 1)
- `hp` (INTEGER, sisa nyawa saat ini)
- `maxHp` (INTEGER, nyawa maksimum)
- `mana` (INTEGER, energi sihir saat ini)
- `maxMana` (INTEGER, energi sihir maksimum)
- `gold` (INTEGER, tabungan koin emas)
- `str`, `dex`, `int`, `wis`, `cha`, `con` (INTEGER, nilai atribut 8 - 18)
- `inventory` (TEXT / JSON: array maksimal 6 slot item)
- `statusEffects` (TEXT / JSON: array kondisi misal ['cursed', 'blessed'])

4.2. Tabel `Campaigns`:
- `id` (STRING, Primary Key: misal 'whispering_tavern')
- `title` (STRING, judul kampanye)
- `premise` (TEXT, latar belakang kisah)
- `genre` (STRING: 'dark_fantasy', 'eldritch_mystery', 'gothic_horror')
- `icon` (STRING, emoji representatif)
- `defaultBackgroundId` (STRING, referensi aset gambar)

4.3. Tabel `GameSessions`:
- `id` (STRING/UUID, Primary Key)
- `campaignId` (STRING, Foreign Key -> Campaigns.id)
- `characterId` (STRING, Foreign Key -> Characters.id)
- `currentSceneId` (STRING, ID adegan aktif)
- `turnCount` (INTEGER, jumlah giliran yang telah berlangsung)
- `worldLedger` (TEXT / JSON: catatan fakta dunia & reputasi fraksi)
- `isGameOver` (BOOLEAN, status apakah pemain menang/tewas)
- `savedAt` (DATE)

4.4. Tabel `StoryNodes`:
- `id` (STRING/UUID, Primary Key)
- `sessionId` (STRING, Foreign Key -> GameSessions.id)
- `parentNodeId` (STRING nullable, ID node induk untuk rantai branching)
- `chapterTitle` (STRING, judul babak)
- `location` (STRING, nama area)
- `backgroundId` (STRING, ID aset background)
- `speaker` (STRING, nama tokoh yang sedang berdialog)
- `characterId` (STRING, ID aset sprite pembicara)
- `mood` (STRING: 'tense', 'mysterious', 'triumphant', 'ominous', 'peaceful')
- `dialogueText` (TEXT, narasi sastrawi 2 - 4 kalimat)
- `consequenceNote` (STRING, dampak langsung dari pilihan sebelumnya)
- `choices` (TEXT / JSON, array pilihan aksi beserta DC dan stat type)

5. AI DUNGEON MASTER PROMPT SPECIFICATION & STRICT JSON SCHEMA
================================================================================

Berikut adalah System Prompt resmi yang ditanamkan pada `@google/genai`:
```text
Kamu adalah Dungeon Master (DM) legendaris untuk game Visual Novel Virtual Tabletop (VTT).
Tugasmu adalah merajut narasi interaktif D&D 5E dengan Bahasa Indonesia sastrawi yang imersif, 
atmosferik, dan memikat.

ATURAN STRUKTURAL WAJIB:
1. Respon WAJIB berupa objek JSON murni tanpa pembungkus markdown ```json ```.
2. Setiap pilihan aksi (choices) WAJIB menyertakan nilai kesulitan DC (Difficulty Class antara 8 hingga 16) 
   dan Atribut terkait (STR | DEX | INT | WIS | CHA).
3. Selalu petakan backgroundId dan characterId ke daftar aset resmi yang valid.
4. Perhitungkan dampak terhadap HP dan Gold pemain jika ada peristiwa berbahaya.

SKEMA JSON RESMI:
{
  "chapterTitle": "string (Judul Babak)",
  "location": "string (Nama Lokasi)",
  "backgroundId": "string (Pilih dari: bg_01_tavern, bg_02_cursed_woods, bg_03_sunken_citadel, bg_04_crimson_crypt, bg_05_vampire_castle, bg_06_alchemy_lab, bg_07_smuggler_cave, bg_08_arcane_library, bg_09_dragon_crater)",
  "speaker": "string (Nama Tokoh)",
  "characterId": "string (Pilih dari: char_hero_01 s.d 09 atau char_npc_01 s.d 09)",
  "mood": "tense | mysterious | triumphant | ominous | peaceful",
  "dialogue": "string (2-4 kalimat narasi mendalam yang membangkitkan suasana)",
  "consequenceNote": "string (1 kalimat menceritakan dampak aksi sebelumnya)",
  "stateUpdates": {
    "hpChange": 0,
    "goldChange": 0,
    "receivedItem": null,
    "consumedItem": null,
    "addLedgerFact": "string catatan fakta"
  },
  "choices": [
    {
      "id": "c1",
      "text": "string deskripsi tindakan",
      "statType": "STR | DEX | INT | WIS | CHA",
      "dc": 12,
      "requiredItem": null,
      "tone": "bold | cautious | curious | shrewd"
    }
  ]
}
```
