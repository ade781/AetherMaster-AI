10. PROTOKOL OTOMASI SLICING & PIPELINE DEPLOYMENT KE FRONTEND
--------------------------------------------------------------------------------
1. Generate Image 3x3 Grid Sheet (misal: `pack_1_heroes.png`) dengan Midjourney/DALL-E/Gemini Imagen.
2. Letakkan file hasil generate di root direktori proyek.
3. Jalankan script slicer python otomatis:
   ```bash
   python slice_grid.py pack_1_heroes.png frontend/public/assets/portraits/
   ```
4. Verifikasi bahwa file telah terpotong rapi dengan format nama standar (`char_hero_01_paladin.png`, dst).
5. Frontend React akan secara otomatis menampilkan gambar tanpa perlu konfigurasi ulang kode atau restart server!
